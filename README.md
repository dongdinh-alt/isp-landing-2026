# ISP Landing Page 2026 — "Crimson Orbit"

A static landing page for the ISP bachelor program (Interdisciplinary Business, UEH.ISB × Fu Jen). The site runs as plain files; a small build step only minifies CSS/JS.

```
index.html                 all content (Vietnamese, from "ISP Landing page 2026.xlsx"); loads the *.min.* files
assets/css/main.css        design tokens (from ISB-DESIGN.md) + components + responsive  ← edit this
assets/css/main.min.css    generated by tools/build.sh — do not edit
assets/js/main.js          motion & interactions                                          ← edit this
assets/js/*.min.js         generated by tools/build.sh — do not edit
assets/vendor/             GSAP 3.12.5, ScrollTrigger, Lenis 1.1.13 (self-hosted copies)
assets/fonts/              Mona Sans (3 subsets) + Phosphor Bold subset (generated)
assets/img/                WebP photos; large ones have 2–3 widths for srcset. Hero = hero-2026-* (MarCom KV, desktop from 1200x628.png, mobile from 11.png); og-1200x628.jpg = share image
assets/logo/               ISB / ISP / Fu Jen SVG logos (white for dark backgrounds, *-color for light ones)
tools/build.sh             minify CSS/JS + stamp ?v=<hash> into index.html
tools/build-icons.py       subset Phosphor Bold to the icons in use + regenerate the icon CSS block
```

## Workflow
1. Edit `main.css` or `main.js` (never the `.min` files). Use tokens only — see **Design tokens** below.
2. Added or removed a `ph-*` icon? Run `python3 tools/build-icons.py` (needs `pip install fonttools brotli`).
3. Run `sh tools/build.sh` (needs Node; esbuild comes via npx). It writes the `.min` files and new `?v=` hashes.
4. New photos: export WebP (quality ~72, max ~1600px wide; ~800px for the photo belt) and give the `<img>` `width`/`height`.
   - Major photos (`assets/img/majors/{gm,gt,gs,gst}-{600,1000}.webp`): Unsplash (free licence), cropped to 2:1 because the frame is 3:1 on desktop and 2:1 on phones. Sources: `photo-1542744173-8e7e53415bb0` (gm), `photo-1551288049-bebda4e38f71` (gt), `photo-1511546705877-f449b6f6dcfd` (gs), `photo-1590274853856-f22d5ee3d228` (gst) on images.unsplash.com.

## Stack
- **GSAP 3.12.5 + ScrollTrigger**, **Lenis 1.1.13**: self-hosted in `assets/vendor/`, loaded with `defer`.
- **Mona Sans**: self-hosted variable font (`wdth` 75–125, `wght` 300–900), Vietnamese + Latin subsets, `font-display: swap`. The Latin and Vietnamese files are preloaded. Big numbers use `font-stretch: 125%`.
- **Phosphor Icons, Bold**: an icon-font subset with only the icons in use (~6 KB instead of 150 KB). **Exception:** the three large decorative icons in the wide USP cards (`.bento__deco`) are inline SVGs of the **Light** weight, at the client's request. At 72px, the Bold stroke looked too heavy.

The page still works if the scripts fail. Content shows without animation, because a 3-second guard in `<head>` removes the hidden state.
`prefers-reduced-motion` turns off Lenis, the scroll animations and the counters.

## Hosting
- Serve with **Brotli/gzip** and **HTTP/2**.
- Cache headers:
  - `assets/*`: `Cache-Control: public, max-age=31536000, immutable`. CSS/JS change their `?v=` hash on every build, and new images get new file names.
  - `index.html`: `Cache-Control: no-cache`.
- Lighthouse, run 2026-09-30 against a local Brotli server with simulated slow 4G: mobile 93 (FCP 1.4s, LCP 3.2s, TBT 10ms, CLS 0.002), desktop 100. Total page weight is about 950 KB on mobile (was 3.3 MB).

## Notes
- **Outlined text**: Mona Sans is a variable font whose glyph contours overlap, so `-webkit-text-stroke` would draw the inner overlaps too. Outlined text (currently the footer marquee) therefore uses an SVG filter, `#outline-faint` in `index.html`. It dilates the merged glyph silhouette and knocks out the fill. Apply it with `filter: url(#outline-faint)` on text with a solid colour, and copy the filter with a different `flood-color` for other colours.
- **Rolling numbers**: just before a number rolls, it is typeset once as plain text. Each character's slot (advance + kerning + letter-spacing) is read with a DOM `Range`, and each rolling column gets exactly that width, with glyphs left-aligned as in running text. When the roll ends, the columns are swapped for the plain text, and the positions match to the pixel. Measuring at roll time rather than on load matters: `document.fonts.ready` can resolve before Mona Sans has even been requested.
- **Brand gradients**: `--g-accent` (#DF0100 → #340095) is used alongside the ISI gradients.
- **Pathway field**: the `pathway` checkboxes in the form stay in sync with the "Xây lộ trình" builder (maximum 2).
